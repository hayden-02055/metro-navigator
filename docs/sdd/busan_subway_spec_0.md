# Spec: 부산 도시철도 역간 이동 경로 탐색 시스템

## Overview

부산 도시철도 전 노선(1~4호선, 부산김해경전철, 동해선)의 역 데이터를 그래프로 구성하고,
BFS와 다익스트라(Priority Queue) 알고리즘을 통해 두 가지 경로를 탐색하여 비교 출력하는 시스템.

---

## Goals

- 부산 도시철도 전 노선을 인접 리스트 기반 그래프로 표현한다
- BFS로 최소 환승 경로를 탐색한다
- 다익스트라(heapq)로 최단 시간 경로를 탐색한다
- 두 결과를 나란히 비교 출력한다
- 사용자가 출발역/도착역을 직접 입력할 수 있다

## Non-Goals

- GUI 또는 시각화는 구현하지 않는다
- 실시간 열차 운행 정보는 반영하지 않는다
- 요금 계산은 포함하지 않는다

## Architecture

```
busan_subway.py
│
├── [Data Layer]
│   ├── LINE1, LINE2, LINE3, LINE4, LINE_BGL, LINE_DONG  # 노선별 역 목록
│   └── TRANSFER_MAP  # 환승역 연결 정보
│
├── [Graph Layer]
│   ├── build_graph()  # 인접 리스트 그래프 생성
│   └── add_transfer()  # 환승 에지 추가
│
├── [Algorithm Layer]
│   ├── bfs(graph, start, end)         # 최소 환승 경로
│   └── dijkstra(graph, start, end)    # 최단 시간 경로 (heapq)
│
└── [Output Layer]
    ├── print_result(start, end)  # 두 알고리즘 결과 비교 출력
    └── interactive()             # 사용자 입력 루프
```

## Function Spec

### `build_graph(lines: dict) -> dict`

- 각 노선의 역 목록을 순회하며 인접 리스트를 생성한다
- 에지 형식: `{ 역이름: [(연결역, 소요시간, 노선명), ...] }`
- 모든 에지는 양방향으로 추가한다

### `add_transfer(graph, station_a, station_b, time=3)`

- 두 역 사이에 환승 에지를 양방향으로 추가한다
- 에지의 노선명은 `"환승"`으로 표기한다

### `bfs(graph, start, end) -> (path, transfers, total_time)`

- `deque`를 사용한 BFS로 최소 환승 경로를 탐색한다
- 상태: `(환승횟수, 소요시간, 현재역, 현재노선, 경로)`
- 방문 체크: `(역, 노선)` 쌍으로 중복 방문 방지
- 반환: `(경로 리스트, 환승 횟수, 총 소요시간)`
- 경로 없을 시: `(None, None, None)` 반환

### `dijkstra(graph, start, end) -> (path, transfers, total_time)`

- `heapq`를 사용한 다익스트라로 최단 시간 경로를 탐색한다
- 힙 상태: `(소요시간, 환승횟수, 현재역, 경로)`
- 방문 체크: 역별 최단 거리 딕셔너리(`dist`)로 중복 처리 방지
- 반환: `(경로 리스트, 환승 횟수, 총 소요시간)`
- 경로 없을 시: `(None, None, None)` 반환

### `print_result(start, end)`

- BFS와 다익스트라 결과를 나란히 출력한다
- 출력 형식:
  ```
  ============================================================
    출발: {start}  →  도착: {end}
  ============================================================

  [BFS] 최소 환승 경로
    경로 ({n}개역): 역1 → 역2 → ... → 역N
    환승: {n}회 / 소요: 약 {n}분

  [다익스트라] 최단 시간 경로
    경로 ({n}개역): 역1 → 역2 → ... → 역N
    환승: {n}회 / 소요: 약 {n}분
  ```

### `interactive()`

- 사용자로부터 출발역/도착역을 반복 입력받는다
- 존재하지 않는 역 입력 시 오류 메시지 출력 후 재입력 요청
- `q` 입력 시 종료
