# 부산 도시철도 역간 이동 경로 탐색 시스템

부산 도시철도 전 노선(1~4호선, 부산김해경전철, 동해선)을 **인접 리스트**로 표현하고,
**BFS**와 **다익스트라**로 두 가지 경로를 탐색하여 비교 출력하는 프로그램입니다.

- **BFS (deque / 0-1 BFS)** → 최소 환승 경로
- **다익스트라 (heapq)** → 최단 시간 경로

## 실행 방법

```bash
cd src
python3 busan_subway.py
```

실행하면 먼저 테스트 케이스 결과가 출력되고, 이어서 대화형 입력 모드로 진입합니다.

```
출발역> 남포
도착역> 수영
```

- 존재하지 않는 역을 입력하면 오류 메시지 후 다시 입력받습니다.
- 동명이역(예: `재송`)은 `재송(동해선)`처럼 노선을 붙여 입력합니다.
- `q` 를 입력하면 종료합니다.

## 인접 리스트 모델

```python
GRAPH = {
    "서면": [
        ("범내골", 2, "1호선"),
        ("부전",  2, "1호선"),
        ("가야",  2, "2호선"),
        ("전포",  2, "2호선"),
    ],
    ...
}
```

- **노드** = 역이름(문자열)
- **에지** = `(이웃역, 소요시간(분), 노선명)`, 일반 인접역 이동은 **2분**
- **환승역**(서면·연산·동래 등)은 **한 노드**에 여러 노선의 에지가 함께 모입니다.
  탐색 중 직전 주행 노선과 다른 노선의 에지로 이동하면 **환승**으로 보고 **3분**을 더합니다.
- 환승 표시가 없는 **동명이역**(좌천·재송·센텀·민락·망미·거제 등 물리적으로 다른 역)은
  `재송(동해선)` 처럼 노선을 붙여 **서로 다른 노드**로 구분합니다.

## 클래스 구성

| 클래스 | 역할 |
|--------|------|
| `RouteResult` | 탐색 결과(경로/환승/시간)를 담는 값 객체 |
| `BusanMetro` | 인접 리스트(`GRAPH`) 보관 + `bfs()` / `dijkstra()` |
| `MetroApp` | 결과 출력(`print_result`) + 사용자 입력 루프(`interactive`) |

## 알고리즘

| 메서드 | 자료구조 | 목적 | 비용 우선순위 |
|--------|----------|------|----------------|
| `bfs` | `deque` (0-1 BFS) | 최소 환승 | (환승횟수, 시간) |
| `dijkstra` | `heapq` | 최단 시간 | (시간, 환승횟수) |

두 메서드 모두 `RouteResult` 를 반환하며, 경로가 없으면 `found == False` 입니다.
방문 체크는 `(역, 노선)` 단위로 하여 같은 역이라도 다른 노선으로 도달하는 경우를 구분합니다.

## 참고 사항 (데이터 특이점)

- `data/busan_metro.csv` 를 그대로 반영해 인접 리스트를 만들었습니다. 일부 항목은 실제 운행
  정보와 다를 수 있습니다.
- CSV에서 1호선과 4호선에 같은 이름(낙민·충렬사·명장·서동)이 환승 표시 없이 중복 등재되어
  있어, 두 노선 간 이동은 표시된 환승역(동래)을 경유합니다. 이 역들은 인접 리스트에서
  `명장(1호선)` / `명장(4호선)` 처럼 구분되어 표시됩니다.
